QuickPeek Support / 技术支持

Last updated / 最后更新：2026-11-13

English · 简体中文 · Privacy Policy / 隐私政策

English

Contact and availability

Support: hantmac@outlook.com

QuickPeek is a macOS Quick Look extension for browsing folders and ZIPs and reading supported files in Finder’s preview window. This support page is being prepared for the product; it does not mean QuickPeek has passed App Review or is available for purchase.

Enable QuickPeek

  1. Open the QuickPeek app once. It provides a short, skippable setup guide, not a separate file workspace.
  2. Open System Settings and locate the Quick Look extensions. The location varies by macOS version; look under extensions in General → Login Items & Extensions, or search System Settings for extensions.
  3. Enable QuickPeek. The app does not change this setting for you or claim that opening Settings proves it is enabled.
  4. Try the bundled sample in Finder. You can then quit the setup app; it does not need to keep running.

Everyday use

  1. Select a folder or ZIP in Finder and press Space.
  2. Browse the folder tree in the preview window. Select a supported file to read it on the right.
  3. Click an earlier part of the path to return to that folder.
  4. Expand All is on by default and remembers your choice. Its switch is in the preview, not the setup app. Expansion reads directory information; it does not preselect ordinary files or render their contents.
  5. Use the Quick Look window’s standard close control when finished.

Formats and limits

QuickPeek currently previews UTF-8/UTF-16 text, supported ImageIO images and PDFKit documents. The primary end-to-end test files are TXT, PNG and PDF.

ZIP support is limited to unencrypted, single-volume ZIP32 archives with stored or deflate compression. ZIP64, encrypted or split ZIPs, and ZIPs nested inside ZIPs are not supported. Automatic expansion does not enter other ZIP files on disk. File sizes, directory depth, item counts and resource budgets are limited; very large or unusual files may show a limit or unsupported-format message rather than a preview.

Files are read for preview, not edited. QuickPeek does not provide archive extraction; any Uncompress button in the system title bar belongs to macOS.

Troubleshooting

I only see the system’s generic preview. Check that QuickPeek is enabled in the Quick Look extensions settings, then close and reopen the preview. If another extension supports the same type, macOS chooses the extension. QuickPeek does not change other extensions or their priority. Do not reset all Quick Look caches as a first step.

Some folders did not expand. Expansion has resource limits. Read the status message, expand individual folders, or turn Expand All off and browse manually.

The file cannot be read. It may be unsupported, damaged, over a resource limit, or unavailable under the current macOS access permissions. Try a small TXT, PNG or PDF in the bundled sample. Full Disk Access is not required or requested.

Arrow keys or Escape do not behave as expected. Keyboard focus in Finder’s remote Quick Look view is still being validated in the current development version. Use the native folder controls, path links and standard close button. This is not a claim that every keyboard workflow has passed testing.

Purchases and refunds

The planned model is a one-time App Store purchase, not a subscription. Availability and final local prices are shown by Apple when the product becomes available. Payments and refunds are handled by Apple; see Report a Problem for purchase issues. Do not send payment-card details to support.

Reporting a problem

Email the macOS version, QuickPeek version, file type, steps and the message you saw. If possible, reproduce the issue using a small, non-sensitive sample. Do not attach private documents or screenshots containing private file names unless you choose to share them. There is no automatic upload of your files or local diagnostic reports.

简体中文

联系方式与当前状态

支持邮箱：hantmac@outlook.com

QuickPeek 是 macOS 快速查看扩展，用于在 Finder 的预览窗口内浏览文件夹、ZIP 和阅读支持的文件。本支持页为产品准备中资料，不表示应用已通过 Apple 审核或可以购买。

启用 QuickPeek

  1. 打开一次 QuickPeek App。它只有简短、可跳过的设置引导，不是独立文件工作区。
  2. 打开系统设置，找到“快速查看”扩展。入口随 macOS 版本不同，通常位于“通用 → 登录项与扩展”的扩展部分，也可在系统设置搜索扩展。
  3. 手动启用 QuickPeek。App 不会替你修改设置，也不会把打开设置页面当成已经启用。
  4. 在 Finder 中试用捆绑样本。之后可以退出引导 App，日常不需要它保持运行。

日常使用

  1. 在 Finder 选中文件夹或 ZIP，按空格。
  2. 在预览窗口的目录树中浏览，选中支持的文件后在右侧阅读。
  3. 点击路径中的上级位置返回。
  4. 展开全部默认开启并记住选择，开关只在预览中。展开仅处理目录信息，不自动选择普通文件或渲染正文。
  5. 使用快速查看窗口的标准关闭按钮结束。

格式与限制

当前可预览 UTF-8／UTF-16 文本、ImageIO 支持的图片和 PDFKit 文档。主要端到端测试样本为 TXT、PNG、PDF。

ZIP 仅支持未加密、单卷 ZIP32 的 stored／deflate 压缩。不支持 ZIP64、加密、分卷和 ZIP 内嵌 ZIP；自动展开也不会进入磁盘上的其他 ZIP。文件大小、目录深度、项目数量和资源消耗有限制，过大或特殊文件可能显示超限或不支持提示。

QuickPeek 只读预览，不编辑文件，也不提供解压功能；系统标题栏的“解压”按钮由 macOS 提供。

常见问题

仍显示系统默认预览。 确认快速查看设置中已启用 QuickPeek，再关闭并重新打开预览。如果有其他扩展支持同一文件类型，由 macOS 决定调用哪个；QuickPeek 不会改变其他扩展或优先级。不要先重置所有快速查看缓存。

部分文件夹没有展开。 自动展开有资源预算。请查看状态提示、单独展开目录，或关闭展开全部后手动浏览。

文件无法读取。 可能不支持、损坏、超过限制，或当前 macOS 权限不足。可先试用捆绑样本中的小型 TXT、PNG 或 PDF；不需要，也不会请求完全磁盘访问权限。

方向键或 Escape 不符合预期。 当前开发版本中 Finder 远程预览的键盘焦点仍在验证。可使用原生目录控件、路径链接和标准关闭按钮；这不代表所有键盘流程已经验收。

购买与退款

计划通过 App Store 一次性买断，不采用订阅。是否可购买及最终本地价格以 Apple 展示为准。付款与退款由 Apple 处理，可访问 报告问题；不要向支持邮箱发送银行卡信息。

反馈问题

请说明 macOS 版本、QuickPeek 版本、文件类型、操作步骤及错误提示。尽量使用不含隐私的小型样本复现。除非你主动选择分享，否则不要附上私人文件或含私人文件名的截图。App 不会自动上传文件或本机诊断报告。
